# 通話記録システム v1（完全無料構成）設定手順

所要時間：約30分（1〜2はPC、3はスマホ）／ランニングコスト 0円

---

## 1. Gemini APIキーを取得（3分）
1. https://aistudio.google.com を開く
2. **左サイドバー一番下の鍵アイコン🔑** をクリック
3. 「APIキーを作成」→ プロジェクトを選択（なければ新規作成）
4. `AIza...` で始まるキーをコピー

## 2. GASを設置（10分）
1. https://script.google.com → 「新しいプロジェクト」
2. code.gs の中身を全文貼り付け（元の内容は消す）
3. 左下の **⚙プロジェクトの設定 → スクリプト プロパティ** で2件登録
   - `GEMINI_API_KEY`：手順1のキー
   - `API_TOKEN`：好きな英数字（後で検索アプリの合言葉になる）

   ※コードには書かないので、**後でコードを貼り直しても設定は消えません**
4. 上部の関数選択で **setup** を選び ▶実行 → アクセス承認
5. 実行ログに「セットアップ完了！」と出ればOK
6. **checkSetup** を実行すると、キー・フォルダ・シート・トリガーの状態を一覧で確認できます

自動で作られるもの：
- Drive「通話記録システム」フォルダ（受信／処理済み／エラー）
- スプレッドシート「通話記録DB」（通話記録シート・顧客マスタシート）
- 5分毎の取込トリガー ＋ 毎日3時の音声お掃除トリガー

## 3. FolderSyncを設定（スマホ・10分）
※Autosyncは無料版だと10MB超が同期できないため、FolderSyncを使います

1. Playストアで **「FolderSync」**（Tacit Dynamics／無料・広告あり）をインストール
2. アカウント → Google Drive を追加して認証
3. 「同期フォルダを作成」
   - リモート：`通話記録システム/受信`
   - ローカル：`内部ストレージ/Call`
   - 同期タイプ：**リモートへアップロード**（片方向）
   - スケジュール：15分毎 など
   - 「削除を同期しない」設定にしておくと安全
4. 電池の最適化からFolderSyncを除外（バックグラウンド動作に必須）

## 4. 動作確認
テスト通話 → 5〜20分待つ →「通話記録DB」に
日時・名前・要約・全文の行が増えれば成功

## 無料運用のポイント

### 無料枠の上限
Gemini無料枠は 15回/分・1,500回/日 程度（モデル・時期により変動）。
1日20〜30通話なら余裕。上限に当たっても止まらず、翌日以降に自動で続きから処理します。

### 過去の録音も自動で取り込まれます
録音は**新しい順**に処理されるため、直近の通話がすぐ見られます。
過去分（1月分〜）は残り枠で自動消化します（無料枠の都合で数日〜数週間かかる場合あり）。

### Drive容量の自動管理
録音は約1MB/分。無料15GBを守るため、**処理済み音声は90日でゴミ箱へ自動移動**します
（要約・全文テキストはシートに永久保存＝検索閲覧に支障なし）。
- 期間を変える：`AUDIO_KEEP_DAYS: 90` の数字を変更
- 消さない：`AUDIO_KEEP_DAYS: 0`
- ゴミ箱は空にするまで容量を消費するので、時々空にしてください

### モデル名について
`MODEL: 'gemini-3.5-flash'` で動かない場合は自動で `gemini-2.5-flash` に切替を試みます。
両方ダメなら AI Studio 右側「Run settings」のモデル一覧にある名前に書き換えてください。

### プライバシー
無料枠に送った音声はGoogleのモデル改善に使われる場合があります。
記録したくない相手は、電話アプリの自動録音設定で
「特定の番号を除くすべての通話」を選べば除外できます。

## 困ったとき
| 症状 | 確認 |
|---|---|
| 何かおかしい | まず **checkSetup** を実行。キー・フォルダ・シート・トリガーの過不足が分かる |
| PWAが「応答がありません」 | GASの「実行数」でエラー確認。デプロイの「アクセスできるユーザー」＝全員も確認 |
| 行が増えない | 受信フォルダにファイルが来ているか／GASの実行数（左メニュー）でエラー確認 |
| 状態が「RATE_LIMIT」で止まる | 無料枠上限。放置で翌日自動再開 |
| 状態が「ファイル名形式外」 | エラーフォルダを確認。ファイル名を教えてください（パーサ調整します） |
| 45MB超が飛ばされる | 「大容量スキップ」表示。18〜45MBはFiles API経由で自動処理されます（約45分の通話まで対応） |
